A base de páginas e candidaturas é a validação completa em [questionnaire-ready-v2.md](questionnaire-ready-v2.md); os identificadores entre parênteses apontam para as decisões auditadas naquela versão.

## Regras de implementação

- Uma resposta “nenhuma destas medidas” não deve ser pontuada.
- “Sem posição identificada” é exibido no radar e excluído apenas do denominador daquela decisão.
- A ordem de cartões deve distribuir, dentro da própria pergunta, a pontuação de prioridade; ela não altera os 20% de cada macrotema.
- Q01 substitui as antigas perguntas separadas de tributação e regra fiscal. As perguntas sobre drogas, aborto e minerais foram retiradas: tinham cobertura documental insuficiente para ter o mesmo peso das demais.
