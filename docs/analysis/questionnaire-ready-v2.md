## Itens que não devem entrar automaticamente

Q08 contém uma alternativa sem base exclusiva (“financiar ou contratar rede privada”) e deve ser removida ou reformulada antes da publicação. Q18 tem cobertura explícita só para duas candidaturas; pode ser mantida como pergunta informativa, mas não deve ter o mesmo peso de uma decisão com ampla cobertura. O restante está pronto para a etapa de implementação, com o aviso de cobertura exibido por candidatura.
